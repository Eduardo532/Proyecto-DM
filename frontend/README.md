# Interfaz de Virtual Dungeon Master

React + TypeScript + Vite + Tailwind + Konva. Instrucciones en [`docs/desarrollo.md`](../docs/desarrollo.md).

```bash
npm install
npm run dev        # http://localhost:5173 (con el backend en el puerto 8000)
npm run typecheck
npm test
npm run build      # genera dist/, que el backend sirve en producción
```
